# EMF_GPS_Multicaster_Map_Webserver

Receiver for Multicast GPS data from Tildagon App
https://github.com/mallyhubz/Tildagon_GPS_Multicaster

To start : node server.js

Open webbrowser to http://localhost:8080

The page will show a list of received locations on the left, click follow to follow the user on the map
